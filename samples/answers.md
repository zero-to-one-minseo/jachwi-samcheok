# 가상 샘플 정답표

- 샘플은 `tools/make_samples.py`로 그린 가상 계약서다. 이름·주소·전화·주민번호·계좌는 모두 지어낸 값이다(0으로 채운 번호).
- 기준 번호는 `criteria.csv`의 번호다. 등급은 **규칙 적용 뒤(화면에 나오는) 등급**이다.
- 형식은 `기준 번호 : 기대 등급`이다. 결과 화면의 "기준번호:등급" 한 줄 목록과 맞춰 본다.
- 칸은 셋으로 나눈다.
  - **꼭 나와야 함:** 빠지면 놓친 수에 센다.
  - **나와도 됨:** 계약서에 없어서 "찾지 못함"으로 나올 수 있는 확인 필요 카드. 헛경보로 세지 않는다.
  - **헛경보:** 이렇게 나오면 헛경보 수에 센다.
- criteria.csv의 주의 신호·괜찮은 모습은 샘플 문장을 글자 그대로 옮기지 않았다. 그래도 샘플을 기준 목록에 맞춰 만들었으니 이 점수는 부풀어 있다. 발표 숫자는 보류 샘플로 잰다.
- 설계(설계_구현방법.md 12장)는 빈 계약서 양식에 손으로 채워 찍은 사진을 권한다. 이 파일들은 그 전에 쓰는 대체 샘플이다. 손글씨 특약은 글꼴로 흉내 낸 것이라, 실제 손글씨 읽기 성능은 손으로 쓴 샘플로 따로 잰다.

## 샘플 A (sample_a.jpg, 시연용 월세 계약서)

사진처럼 1.3도 기울이고 그림자·잡음을 넣었다. 손글씨 특약 1줄(6번)이 있다.

**꼭 나와야 함**

```
관리-01 : 확인 필요
퇴실-01 : 주의
수리-01 : 주의
기간-05 : 확인 필요
생활-02 : 확인 필요
기간-01 : 괜찮음
퇴실-02 : 괜찮음
전입-02 : 괜찮음
```

| 기준 | 근거가 되는 원문 | 메모 |
|---|---|---|
| 관리-01 | 관리비 월 120,000원 (정액) | 코드 규칙. 읽은 값: 금액 있음, 120000, 정액, 항목별 금액 없음. 계산식 120,000 ≥ 100,000 |
| 퇴실-01 | 3) 퇴실 시 청소비 10만 원을 보증금에서 공제한다. | 방 상태와 관계없이 일괄 공제 |
| 수리-01 | 4) 수리비는 전부 임차인 부담으로 한다. | 범위 없는 전부 부담 |
| 기간-05 | 5) … 1~2개월 전에 알리고, 새 임차인의 중개보수는 임차인이 부담한다. | 질문 전용 줄이라 확인 필요가 상한. 화면에 `1~2개월`이 취소선 없이 글자 그대로 보여야 한다 |
| 생활-02 | 6) 반려동물 금지. 어기면 계약 해지함 (손글씨) | 손글씨 = 예. 질문 전용 줄이라 확인 필요 |
| 기간-01 | 기간 2027년 3월 1일부터 2028년 2월 29일까지 (12개월) | 날짜가 분명함 |
| 퇴실-02 | 2) 시설물의 노후화나 통상 생길 수 있는 파손은 원상복구 의무에 포함되지 않는다. | |
| 전입-02 | 1) 임차인은 잔금 지급일에 전입신고와 확정일자를 받고, 임대인은 그다음 날까지 … 담보권을 설정하지 않는다. | |

**나와도 됨**

```
보증-01 : 확인 필요
생활-01 : 확인 필요
기간-02 : 확인 필요
```

**헛경보**

- 퇴실-01, 수리-01 말고 주의가 하나라도 나옴
- 퇴실-02, 전입-02, 기간-01이 주의로 나옴
- 생활-02(손글씨)가 괜찮음으로 나옴

**그 밖에 볼 것**

- 문서 종류: 계약서 / 계약 종류: 월세 / 숨은 지시: 없음
- 인용에 전화(010-0000-0000), 주민등록번호(000000-0000000), 계좌(000-00-000000)가 들어가면 화면에서 가려져야 한다. 날짜(2027년 3월 1일)는 가려지면 안 된다.
- 화면 기대(설계 11장): 관리비 카드 1, 빨강 2, 노랑 2, 접힌 초록 3

## 샘플 Y (sample_y.jpg, 연세 계약서)

1년분 선세 330만 원, 보증금 30만 원. 1.1도 기울임. 손글씨 없음.

**꼭 나와야 함**

```
관리-01 : 참고
보증-02 : 확인 필요
기간-04 : 확인 필요
퇴실-01 : 주의
기간-01 : 괜찮음
```

| 기준 | 근거가 되는 원문 | 메모 |
|---|---|---|
| 관리-01 | 관리비 월 10,000원 (공용 전기·계단 청소) | 코드 규칙 "10만 원 미만 → 참고(포함 항목 확인)" |
| 보증-02 | 1) 중도 퇴실 시 선세는 반환하지 않는다. | 질문 전용 줄. AI가 주의를 줘도 코드가 확인 필요로 내린다 |
| 기간-04 | 2) 임차인은 남은 기간을 임의로 양도할 수 있으며, 양도 계약은 임차인과 양수인이 직접 한다. | 지금은 확인 날짜가 비어 질문 전용으로 다뤄지니 확인 필요. 기준 담당이 민법 제629조 원문을 열어 보고 확인 날짜를 적은 뒤에는 **주의**로 바꿔 잰다(주의 신호 "넘길 때 계약은 세입자끼리 하고 집주인은 관여하지 않는다"에 해당) |
| 퇴실-01 | 3) 보증금은 퇴실 시 청소비와 공과금을 정산한 뒤 반환한다. | 금액 없는 청소비 정산 |
| 기간-01 | 기간 2027년 3월 1일부터 2028년 2월 29일까지 (1년) | |

**나와도 됨**

```
생활-01 : 확인 필요
보증-01 : 확인 필요
기간-05 : 확인 필요
```

**헛경보**

- 퇴실-01 말고 주의가 나옴(기간-04는 위 조건대로)
- 보증-02가 괜찮음으로 나옴

**그 밖에 볼 것**

- 계약 종류: 연세(또는 선세). 월세로 나오면 틀린 것으로 센다.
- 선세 금액 330만 원이 관리비로 잘못 읽히지 않는지(관리비 50만 원 초과 규칙에 걸리면 잘못 읽은 것이다).

## 샘플 B (sample_b.pdf, 깨끗한 계약서 2쪽)

글자 층이 없는 그림 PDF다(스캔본과 같음). 인용 대조를 넣으면 이 파일은 대조를 건너뛰는 쪽으로 간다.

**꼭 나와야 함**

```
관리-01 : 괜찮음
```

- 관리비 월 120,000원 정액, 항목별 금액 있음(일반(공용)관리비 50,000 + 수도료 20,000 + 인터넷 사용료 20,000 + TV 사용료 10,000 + 기타관리비 20,000 = 120,000). 코드 규칙 "정액 · 10만 원 이상 · 항목별 금액 있음 → 괜찮음, 항목 표".

**괜찮음 또는 카드 없음** (화면은 괜찮음을 4개까지만 보이니, 없어도 놓친 수로 세지 않는다)

```
기간-01 : 괜찮음
수리-01 : 괜찮음
퇴실-02 : 괜찮음
전입-02 : 괜찮음
기간-03 : 괜찮음
퇴실-01 : 괜찮음
```

| 기준 | 근거가 되는 원문 |
|---|---|
| 기간-01 | 2027년 3월 1일부터 2029년 2월 28일까지 (24개월) |
| 수리-01 | 제1조(수리) 주요 설비의 노후·불량 수선은 임대인, 고의·과실 파손과 소모품은 임차인 |
| 퇴실-02 | 제2조 단서: 시설물의 노후화나 통상 생길 수 있는 파손은 원상복구 의무에 포함되지 않는다 |
| 전입-02 | 특약 1) 전입신고·확정일자, 다음 날까지 담보권 설정 안 함 |
| 기간-03 | 특약 2) 계약 기간 중 보증금과 월세는 바꾸지 않는다 |
| 퇴실-01 | 특약 3) 퇴실 청소는 임차인이 직접 하며, 따로 청소비를 받지 않는다 |

**나와도 됨**

```
보증-01 : 확인 필요
생활-01 : 확인 필요
기간-02 : 확인 필요
기간-05 : 확인 필요
```

- 보증-01은 제2조에 "같은 날 보증금을 돌려준다"가 있지만 질문 전용 줄이라 확인 필요가 상한이다.

**헛경보**

- 주의가 하나라도 나옴
- 관리-01이 확인 필요로 나옴(항목 합계를 못 읽었다는 뜻)

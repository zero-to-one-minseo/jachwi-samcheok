# 가상 샘플 정답표

- 샘플은 `tools/make_samples.py`로 그린 가상 계약서다. 이름·주소·전화·주민번호·계좌는 모두 지어낸 값이다(0으로 채운 번호).
- 기준 번호는 `criteria.csv`의 번호다. 등급은 **규칙 적용 뒤(화면에 나오는) 등급**이다.
- 형식은 `기준 번호 : 기대 등급`이다. 결과 화면의 "기준번호:등급" 한 줄 목록과 맞춰 본다.
- 칸은 셋으로 나눈다.
  - **꼭 나와야 함:** 빠지면 놓친 수에 센다.
  - **나와도 됨:** 계약서에 없어서 "찾지 못함"으로 나올 수 있는 확인 필요 카드. 헛경보로 세지 않는다.
  - **헛경보:** 이렇게 나오면 헛경보 수에 센다.
- criteria.csv의 주의 신호·괜찮은 모습은 샘플 문장을 글자 그대로 옮기지 않았다. 그래도 샘플을 기준 목록에 맞춰 만들었으니 이 점수는 부풀어 있다. 발표 숫자는 보류 샘플로 잰다.
- 설계(설계_구현방법.md 12장)는 빈 계약서 양식에 손으로 채워 찍은 사진을 권한다. 이 파일들은 그 전에 쓰는 대체 샘플이다. 손글씨 특약은 글꼴로 흉내 낸 것이라, 실제 손글씨 읽기 성능은 손으로 쓴 샘플로 따로 잰다.

| 생활-02 | 6) 반려동물 금지. 어기면 계약 해지함 (손글씨) | 손글씨 = 예. 질문 전용 줄이라 확인 필요 |

**나와도 됨**

```
보증-01 : 확인 필요
생활-01 : 확인 필요
기간-02 : 확인 필요
```

**헛경보**

- 생활-02(손글씨)가 괜찮음으로 나옴

**그 밖에 볼 것**

- 문서 종류: 계약서 / 계약 종류: 월세 / 숨은 지시: 없음
- 인용에 전화(010-0000-0000), 주민등록번호(000000-0000000), 계좌(000-00-000000)가 들어가면 화면에서 가려져야 한다. 날짜(2027년 3월 1일)는 가려지면 안 된다.
- 화면 기대(설계 11장): 관리비 카드 1, 빨강 2, 노랑 2, 접힌 초록 3

## 샘플 B (sample_b.pdf, 깨끗한 계약서 2쪽)

```

기간-03 : 괜찮음
퇴실-01 : 괜찮음
```

| 전입-02 | 특약 1) 전입신고·확정일자, 다음 날까지 담보권 설정 안 함 |

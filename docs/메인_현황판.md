| 일이 두 갈래라 어느 쪽도 끝나지 않는다 | 21:00 체크포인트에서 둘 중 하나를 줄일지 정한다 |
| 외부 데이터 요건을 못 채운다 | 실거래가 API를 일찍 확인한다. 안 되면 멘토에게 인정 범위를 묻는다 |
| 조사 데이터가 적어 현황판이 빈약하다 | 실거래가로 동네별 시세 기준선을 깔고, 조사값은 그 위에 얹는다 |
| 개인정보(집주인 번호, 호수) | 시트와 앱에 넣지 않는다. 건물·동네 단위로만 |
| 제출 마감을 놓친다 | 11:15 제출을 고정한다 |

## 메인이 매번 하는 일

1. 다른 세션의 메시지와 `인계/Codex/`를 보고 3장 수신함에 적는다.
2. 세션이 '끝났다'고 하면 결과 파일을 직접 열어 확인한 뒤 2장 상태를 바꾼다.
3. 결정이 나면 4장으로 옮기고, 5장에서 지운다.
4. 1장의 '낡음' 표시가 남아 있으면, 그 문서를 고칠지 민서에게 묻는다.

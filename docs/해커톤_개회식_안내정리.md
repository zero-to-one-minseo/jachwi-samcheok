## 문제를 정하고 발표 첫 장 쓰기

운영진은 문제를 찾을 때 아래 네 질문 중 하나에서 출발하라고 안내했다. [문제 발굴 질문](../IMG_6754.HEIC)

- 이번 학기에 같은 일을 세 번 이상 한 적이 있는가?
- 메모, 캡처, 단톡방, 엑셀로 메우고 있는 임시방편은 무엇인가?
- ‘원래 그런 거지’ 하고 넘어갔지만 아까웠던 순간은 언제인가?
- 기다리거나, 헤매거나, 같은 것을 다시 물어본 순간은 언제인가?

팀원 중 적어도 한 명이 **직접 겪었거나 관찰한 일**을 고른다. 그 문제를 **사용자 한 명, 장면 하나, 한 번에 끝나는 과업 하나**로 좁힌다. 비슷한 서비스가 있다면 어떤 점이 부족한지 한 줄로 쓴다. 운영진이 발표 첫 장에 쓰라고 제시한 문장은 다음과 같다. [문제를 좁히는 규칙과 발표 문장](../IMG_6755.HEIC)

> [누가]는 [언제] [무엇] 때문에 [얼마만큼의 비용]을 치른다.

## 개회식에서 소개한 LLM API

아래는 개회식 슬라이드에 나온 설명이다. 무료 한도와 조건은 사용 전에 각 서비스에서 확인하라고 안내했다. [LLM API 안내](../IMG_6759.HEIC)

| 서비스 | 슬라이드 안내 |
| --- | --- |
| Gemini API | Google AI Studio 무료 등급. 입력 내용이 품질 개선에 쓰일 수 있어 개인정보 입력 금지 |
| Groq | 무료 등급, 빠른 응답, 오픈소스 모델 |
| OpenRouter | `:free` 모델은 한도가 작아 팀 전체가 쓰기에는 부족할 수 있음 |
| Cloudflare Workers AI | 하루 1만 Neuron 무료로 소개. Cloudflare 계정 필요 |

API 키는 `.env`에 보관한다. 소스코드에 직접 쓰거나 GitHub에 올리는 것은 피하라고 안내했다.

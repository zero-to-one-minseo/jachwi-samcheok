- 단독/다가구: 시군구코드, 법정동명(`umdNm`), 주택유형(단독/다가구), 계약기간, 계약구분(신규/갱신), 갱신요구권 사용, 보증금(`deposit`, 만원), 월세(`monthlyRent`, 만원), 계약면적(`totalFloorAr`), 건축년도, 계약 년·월·일, 종전 보증금·월세. **건물명·지번 전체는 없음.**

- 오피스텔: 위 칸 + 단지명(`offiNm`), 지번, 전용면적, 층.
- 민간 사이트 시세.com의 단독/다가구 화면도 "동·계약일·신규/갱신·보증금·월세·면적·준공연도"만 보여 줘서, 위 기억과 맞음 [2차].

**삼척시 코드 (LAWD_CD)**
- **51230** 을 써야 함. 2023-06-11 강원특별자치도 출범으로 지역코드 앞자리가 42 → 51로 바뀜 [확인: 카카오 개발자 공지 https://devtalk.kakao.com/t/api-6-12-11-00/129914 , "법정동·행정동 코드 앞자리 42→51"].
- 예전 코드 42230으로 2023년 6월 이전 자료를 조회해야 하는지는 **확인 못 함**. 처음 호출할 때 51230으로 2022년 월을 넣어 결과가 나오는지 보면 됨.
- 민간 사이트(bolta.io 주소 `/area/51230` = 강원특별자치도 삼척시)도 51230을 씀 [2차].
- 교동·정상동·당저동·남양동의 10자리 법정동코드는 **확인 못 함**. 행정안전부 행정표준코드관리시스템(https://www.code.go.kr)에서 찾아야 함.
- 참고 [2차, 위키]: 행정동 '교동' 안에 법정동 교동·갈천동·마달동·우지동·증산동이 있고, 행정동 '남양동' 안에 남양동·사직동·오분동·적노동·조비동이 있음. 당저동은 행정동 성내동 소속. 실거래 자료는 **법정동 이름**으로 나오니 현황판도 법정동 기준으로 묶어야 함.

**주의할 점**
- 자료는 임차인이 확정일자를 받은 계약(또는 전월세 신고분)만 담김. 확정일자를 안 받은 학생 원룸 계약은 빠질 수 있음 [추측].
- 단독/다가구는 지번이 일부만 나와서 **건물 하나하나를 지도에 찍거나 건축물대장과 잇기 어렵다.** 동 단위 집계가 현실적.
- 단독/다가구의 '계약면적'이 방 하나 면적이 아니라 건물 연면적처럼 큰 값(예: 197.6㎡에 월세 28만)이 섞여 있음 → 큰 면적은 걸러야 함.
- 관리비는 없음.
- API는 시군구 + 한 달 단위라, 1년치면 유형별 12번 호출이면 됨. 한도 걱정은 없음.

### 2-3. 건축물대장 (건축HUB 건축물대장정보 서비스)

- 데이터 이름: 국토교통부_건축HUB_건축물대장정보 서비스
- 안내 페이지: https://www.data.go.kr/data/15134735/openapi.do
- 요청 주소 [확인]: `https://apis.data.go.kr/1613000/BldRgstHubService` (표제부: `/getBrTitleInfo`)
- 요청 값 [확인]: 필수 `serviceKey`, `sigunguCd`(51230), `bjdongCd`(법정동 5자리). 선택 `platGbCd`(0 대지, 1 산, 2 블록), `bun`, `ji`, `startDate`, `endDate`, `_type`(xml/json), `numOfRows`, `pageNo`.
- 제공 범위 [확인]: 기본개요, 총괄표제부, 표제부, 층별개요, 부속지번, 전유공용면적, 오수정화시설, 주택가격, 전유부, 지역지구구역.
- 형식·비용·주기 [확인]: REST, JSON 또는 XML, 무료, **매월** 갱신.
- 한도·승인 [확인]: 개발계정 10,000건, 운영계정은 신청하면 늘림. 개발·운영 모두 자동승인.
- 받을 수 있는 칸 [2차: k-skill 문서 https://raw.githubusercontent.com/NomaDamas/k-skill/main/docs/features/building-register-search.md]: 주용도(`mainPurpsCdNm`, 예: 다가구주택·다세대주택), 연면적(`totArea`), 지상층수, 지하층수, **사용승인일(`useAprDay`)**, 지번주소(`platPlc`), 도로명주소(`newPlatPlc`), 대장 PK. 세대수·가구수 칸 이름은 **확인 못 함**(기억으로는 `hhldCnt` 세대수, `fmlyCnt` 가구수 — 추측).
- **위반건축물 여부 칸: 확인 못 함.** 공개된 안내·명세 요약 어디에도 위반 칸이 안 보임. 공공데이터 분쟁조정 사례에 "건축HUB 건축물대장서비스(위반건축물 API)" 제공을 개인이 신청했다가 **국토부가 거부**한 건이 있음(2025-11-11 공개, 기한 넘겨 반려) [확인: https://www.data.go.kr/odmc/trublMdat/mdatCase/board.do?id=431]. → 위반 여부는 공개 API로 못 받을 가능성이 큼(추측). 정확한 칸 목록은 안내 페이지의 활용가이드 zip에 있음.
- 세움터·정부24 건축물대장 열람은 로그인이 필요함(추측, 이번에 접속 안 함). 위반건축물 표시는 열람본 표제부에 찍혀 나옴(추측).
- 주의: 단독/다가구 전월세는 지번이 일부만 나와서 이 대장과 건별로 잇기 어려움. 연립/다세대·오피스텔은 지번이 있어 이을 수 있음(추측, 칸 확인 필요).

### 2-4. 브이월드 지오코더 API 2.0

- 안내: https://www.vworld.kr/dev/v4dv_geocoderguide2_s001.do
- 요청 주소 [확인]: `https://api.vworld.kr/req/address?service=address&request=getCoord&key=인증키&...`
- 요청 값 [확인]: `type`(PARCEL 지번 / ROAD 도로명), `address`, `crs`(기본 EPSG:4326), `format`(json 기본/xml), `refine`, `simple`.
- 응답 [확인]: status(OK/NOT_FOUND/ERROR), 정제 주소, 좌표 x·y.
- 하루 한도 [확인]: "일일 지오코딩 요청건수는 최대 40,000건".
- **결과 저장 금지 [확인]**: 실시간으로만 쓰고 별도 저장장치나 DB에 저장할 수 없다고 적혀 있음. 현황판에 좌표를 미리 저장해 두는 방식이면 약관에 걸림.
- 키 발급 조건: 브이월드 회원가입 후 인증키 신청, 키에 서비스 도메인을 적음(다르면 `INCORRECT_KEY` 오류) [확인: 오류 설명]. 개발키 기간·운영키 전환은 **확인 못 함**(키 안내 페이지가 404).
- 대안 [추측]: 단독/다가구는 어차피 동 단위라 좌표가 필요 없음. 동 중심점 몇 개만 손으로 넣거나, 도로명주소 좌표 API(행정안전부 business.juso.go.kr)를 검토. 이 대안의 저장 조건은 확인 못 함.
